❖ Technical Requirement Document (TRD) – InteractHub
1. Đăng nhập người dùng (Login)
  • T01User-ID / UserName must not be blank.
  • T02Password must not be blank.
  • T03User account with Admin role is rejected (must use Admin Login endpoint).
  • T04If credentials are valid: Generate JWT Bearer Token (60 min) and return User profile.
  • T05If invalid username or password: Return HTTP 401 Unauthorized.
2. Đăng ký tài khoản (Register)
  • T06UserName must be 3–20 characters, alphanumeric and underscore only.
  • T07Email must be valid format and not already exist in database.
  • T08FullName must be between 2 and 100 characters.
  • T09Password must be ≥ 8 characters with upper, lower, digit and special char.
  • T10Password must be hashed with ASP.NET Core Identity PBKDF2 before storage.
  • T11If valid: Assign default role "User", generate token, return HTTP 201 Created.
3. Đăng nhập Admin (Admin Authentication)
  • T12Admin login endpoint /api/admin/login is AllowAnonymous.
  • T13Only users possessing the "Admin" role can authenticate here.
  • T14Non-admin users attempting login are rejected with HTTP 403 Forbidden.
  • T15Admin token expiration is set to 120 minutes with claim IsAdmin=true.
4. Quản lý Bài viết (Posts)
  • T16Post Content must not be empty unless an image is attached.
  • T17Attached image must not exceed 5MB and must be JPEG/PNG/GIF/WebP.
  • T18Feed posts exclude group posts (GroupId == null). Pagination required.
  • T19Post modification (Edit) is NOT allowed to ensure interaction integrity.
  • T20Only post owner can delete their post (checked via current JWT UserId).
  • T21Shared post references original post; caption is optional.
5. Bình luận (Comments)
  • T22Comment Content must not be blank.
  • T23PostId must exist in database.
  • T24Only author can edit comment (PUT /api/Comments/{id}).
  • T25Only author can delete comment (DELETE /api/Comments/{id}).
  • T26Emits CommentAdded via SignalR CommentHub to all post viewers.
6. Thích bài viết (Likes)
  • T27Target PostId must exist in database.
  • T28Unique constraint on (PostId + UserId) prevents duplicate likes.
  • T29Users can only delete their own like via DELETE .../user/{userId}.
  • T30Like count must be computed via database Count() directly.
7. Kết bạn & Quan hệ (Friendships)
  • T31Users cannot send friend request to themselves (UserId != FriendId).
  • T32New friend requests start with Status = Pending(0).
  • T33Only recipient can Accept(1) or Decline(2) pending friend request.
  • T34Unfriend requires current relationship Status = Accepted.
  • T35Blocked(3) status terminates messaging and friend request visibility.
8. Nhắn tin thời gian thực (Messaging)
  • T36Message Content must not be blank.
  • T371-1 chat requires relationship Status = Accepted before SignalR join.
  • T38Group chat requires valid GroupMembership for the sender.
  • T39Dispatches ReceiveMessage event to recipient via MessageHub < 1s.
  • T40Mark as read updates IsRead = true only for recipient's messages.
9. Nhóm cộng đồng (Groups)
  • T41Group Name is required. Unique URL Slug is generated automatically.
  • T42Creator is automatically registered as first member in GroupMemberships.
  • T43Join requires non-membership; Leave requires existing membership.
  • T44Membership changes emit GroupMemberCountUpdated via SignalR.
10. Khoảnh khắc 24h (Stories)
  • T45Story must contain ImageUrl or Content text.
  • T46Default ExpireAt is exactly CreatedAt + 24 hours.
  • T47Stories past 24 hours are excluded from active story feeds.
  • T48Only owner or Accepted friends can view active stories.
  • T49Only owner can delete their story prior to expiration.
11. Báo cáo & Kiểm duyệt (Post Reports)
  • T50Users cannot report their own post (post.UserId != currentUserId).
  • T51Duplicate Pending report on same post by same user is rejected.
  • T52Reason must match 1 of 7 defined enums; Detail must be ≥ 10 chars.
  • T53Approve report: Save audit copy into PostDeletionLog, delete post, notify author.
  • T54Reject report: Update report status to Rejected, post is preserved.
12. Tìm kiếm & Bảo mật (Search & System Security)
  • T55All search keywords must be sanitized by QueryHelper (anti-SQLi / XSS).
  • T56User search is case-insensitive, capped at max 50 results.
  • T57Search results must never expose PasswordHash or SecurityStamp fields.
  • T58Client search inputs must enforce Debounce ≥ 300ms.
  • T59CORS AllowLocalhost restricts origins to 3000, 3001, 5142.
  • T60SignalR client must configure automatic reconnect withAutomaticReconnect().
